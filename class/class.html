從零開始寫C++

講師

課程簡介

對程式設計感到陌生也沒關係！這不只是一門 C++ 語法教學課，而是從 C++ 出發認識程式設計的基礎課程。
課程將從第一個程式開始，循序學習核心語法與概念，不只教「怎麼寫」，也會帶你理解程式如何運作、背後的邏輯，以及「為什麼要這樣寫」。無需基礎，輕鬆學習，一步步建立程式設計思維。

課程簡介

本課程主要目的是讓沒有網頁設計基礎的同學了解網頁的基本架構與運作方式，並循序漸進學習 HTML、CSS、JavaScript、Flask 與 SQL 等網頁開發技術，建立網頁設計與開發的基礎概念及實作能力。
